# Todo App - Proyecto Final Individual

Aplicación web para la gestión e integración de tareas diarias (Todo App),
enfocada en una interfaz limpia y funcional para optimizar la productividad
personal.

Actualmente el proyecto se encuentra en **fase inicial de diseño y
maquetación**, contando con los wireframes interactivos y la estructura base de
HTML.
