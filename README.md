## Project Overview

Web application designed for efficient personal task and project management. Built with a focus on UX/UI, this tool allows users to organize, filter, and track task statuses through a modern, responsive interface.

## Key Features

- **Task Management:** Create, edit, and filter tasks by status (Pending, In Progress, Completed, Urgent).
- **Calendar & Advanced Search:** Integrated search bar to locate tasks by title or description alongside a date picker filter.
